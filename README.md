# SIA Coursework

This repository contains my activities and coursework for **System Integration and Architecture**.

## Activities

### 1. Lab 01 — Content Rating App

A React application that allows users to rate content using Like and Dislike buttons.

**Features:**
- Like button with count
- Dislike button with count
- React state management
- Button event handling
- CSS styling

**Technologies:**
- React
- JavaScript / JSX
- HTML
- CSS

### 2. Lab 02 — Event Planner Landing Page

A React landing page for an organization that plans personal and corporate events.

**Features:**
- Event planner description section
- Event categories
- Event planning features
- Customer testimonials
- Contact form
- Structured React component layout

**Technologies:**
- React
- JavaScript / JSX
- HTML
- CSS

### 3. Lab 03 — Todo List App

A React application for organizing tasks using headings and associated todo lists.

**Features:**
- Add todo headings
- Add list items under each heading
- Display todo headings and lists dynamically
- Delete todo headings and their associated lists
- Delete individual list items
- Basic CRUD functionality
- Manage application state using React's useState hook

**Technologies:**
- React
- JavaScript / JSX
- HTML
- CSS

**Features:**
- Burger menu grid

- Responsive CSS layout

**Technologies:**
- React
- JavaScript / JSX
- HTML
- CSS
